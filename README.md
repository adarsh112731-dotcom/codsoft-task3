# Portfolio, Landing Page & Calculator Project

## Overview

This repository contains three frontend web development projects built using **HTML, CSS, and JavaScript**:

1. **Personal Portfolio Website**
2. **Capital Fund Landing Page**
3. **Professional Calculator with Keyboard Support**

These projects demonstrate modern web design, responsive layouts, user interaction, and JavaScript functionality.
